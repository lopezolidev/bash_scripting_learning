# 🐚 Prácticas y Automatización en Bash Scripting

Este repositorio contiene una colección de scripts en Bash desarrollados para automatizar tareas, administrar sistemas y optimizar flujos de trabajo en la terminal.

## 🚀 Propósito
El objetivo de este proyecto es documentar mi aprendizaje en el scripting de shell, creando herramientas prácticas para la gestión de entornos Linux, manipulación de directorios, manejo de permisos y automatización de procesos rutinarios.

## 📁 Estructura del Repositorio
* `admin_sistema/`: Scripts para la gestión de usuarios, grupos y control de acceso.
* `automatizacion/`: Tareas programadas, copias de seguridad y despliegues rápidos.
* `redes_utilidades/`: Herramientas de diagnóstico de red y auditoría básica.
* `fundamentos/`: Ejercicios de control de flujo, bucles y parseo de texto (grep, awk, sed).

## ⚙️ Entorno de Ejecución
Los scripts están diseñados y probados nativamente en entornos **GNU/Linux (Debian)**.

**Uso general:**
Para ejecutar cualquier script de este repositorio, asegúrate de otorgar permisos de ejecución previamente:
```bash
chmod +x nombre_del_script.sh
./nombre_del_script.sh
